手機觸控

按鍵模式：左手 ◀ ▶ 移動、▼ 軟降、◀ 上方的 ⤓ 硬降（和 ◀ 之間的距離可在設定調整）；右手 ↺ ↻ 旋轉、最下排 HOLD 暫存。硬降預設「放開才落下」，按到一半發現按錯可以把手指滑出按鈕取消。設定裡的「自訂按鍵位置」可以把每顆按鍵拖到任何地方、個別調整大小。
手勢模式：左右拖曳移動、往下拖軟降、快速下滑硬降、點右半邊順時針、點左半邊逆時針、快速上滑暫存。

場景與音樂

每升一級換一個場景，共 21 關：星空 → 深海 → 竹林 → 極光 → 水墨 → 荷塘月色 → 螢火森林 → 霓虹都市 → 土星環 → 敦煌 → 櫻花 → 長城 → 冰晶洞窟 → 楓紅 → 燈節 → 雨夜 → 仙山 → 海上風暴 → 熔岩 → 飛龍 → 夕陽雲海。過關時會有過場畫面。難度曲線預設「輕鬆」（每 12 行升一級、速度增加得慢），可在設定改成標準或經典。每首曲子會隨你消的行數逐層加入貝斯、鼓、旋律；移動和旋轉的音效會配合當下的和弦。建議戴耳機。設定裡可調「起始等級」直接跳到想玩的場景。

對戰模式

主選單選「對戰模式」：輸入暱稱後可以建立房間（把 4 位數房號或邀請連結傳給朋友），或輸入朋友的房號加入；也可以先跟電腦練習。消行會送垃圾行給對手：雙消 1 行、三消 2 行、Tetris 4 行、T-Spin 雙倍，連擊、Back-to-Back、全消另有加成。場地左邊的紅色量表是即將頂上來的垃圾行，趕快消行可以抵銷。每人的速度依自己消的行數升級；每一局的場景順序都是隨機的，升級時場景會慢慢轉換、不會中斷比賽。

小技巧

方塊落地後有短暫時間可以滑動或旋轉（鎖定延遲）。T 形方塊旋轉塞入縫隙可做 T-Spin；連續消行有 Combo；Tetris / T-Spin 連發有 Back-to-Back 加成。
