操作說明

鍵盤

← → 移動　↓ 軟降　空白鍵 硬降
↑ / X 順時針　Z 逆時針　A 旋轉 180°
C / Shift 暫存　Esc / P 暫停　R 重來

手把（Xbox / PS / 藍牙手把）

十字鍵或左搖桿 移動、軟降　十字鍵↑ / RT 硬降
A / RB 順時針　B / LT 逆時針　Y 旋轉 180°　X / LB 暫存　Start 暫停

手機觸控

按鍵模式：左手 ◀ ▶ 移動、▼ 軟降、◀ 上方的 ⤓ 硬降（和 ◀ 之間的距離可在設定調整）；右手 ↺ ↻ 旋轉、HOLD 暫存。硬降預設「放開才落下」，按到一半發現按錯可以把手指滑出按鈕取消。
手勢模式：左右拖曳移動、往下拖軟降、快速下滑硬降、點右半邊順時針、點左半邊逆時針、快速上滑暫存。

場景與音樂

每升一級換一個場景：星空 → 深海 → 極光 → 水墨 → 霓虹都市 → 櫻花 → 燈節 → 夕陽雲海。過關時會有過場畫面。難度曲線預設「輕鬆」（每 12 行升一級、速度增加得慢），可在設定改成標準或經典。每首曲子會隨你消的行數逐層加入貝斯、鼓、旋律；移動和旋轉的音效會配合當下的和弦。建議戴耳機。設定裡可調「起始等級」直接跳到想玩的場景。

小技巧

方塊落地後有短暫時間可以滑動或旋轉（鎖定延遲）。T 形方塊旋轉塞入縫隙可做 T-Spin；連續消行有 Combo；Tetris / T-Spin 連發有 Back-to-Back 加成。
